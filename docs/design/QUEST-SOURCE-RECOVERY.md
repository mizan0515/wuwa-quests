# 퀘스트 추가 원문

Issue #54: 퀘스트 본문에 빠진 전투·던전·상호작용과 중첩 호출 원문을 보충한다.
QuestData와 QuestNode만 따라가던 추출 경로는 LevelPlay와 그 노드, 참조된 entity,
던전 진입 뒤의 전용 맵, 장면 내부의 화면 문구 호출을 모두 읽지 못했다.

2026-10-08 추출 스냅샷을 사용했다. 실제 클라이언트 버전과 현재 설치본의 동일성은
확인되지 않았다. 설치본을 새로 추출한 결과로 보고하지 않는다.

## 수록 결과와 경계

- 기존 766개 퀘스트를 조사하여 402개에 3,688개 장면을 추가했다.
- 추가 기록은 16,561개 참조 행이며 한국어 본문이 있는 행은 16,558개다.
  반복 수록을 포함하며 서로 다른 문자열의 수와 구분한다.
- `MAIN_YHX_137_1`은 `114000031`의 장면 91, `114000032`의 장면 39에 수록된다.
  화자 없는 중앙 문구이며 인물의 발언으로 편집하지 않는다.
- `Reference`의 e_/l_/f_, 명시적 Flow 호출, 상대 ChangeState, 전용 던전 맵을
  따라간다. q_ 선행 임무 연결과 이름 유사성은 귀속 근거로 사용하지 않는다.
- 전용 던전 맵은 해당 맵의 LevelPlay 전체가 Dungeon 유형인 경우로 제한한다.
  공용 월드 유형과 Dungeon/Quest 등이 섞인 맵은 통째로 따라가지 않는다.
  같은 맵에서도 직접 참조된 LevelPlay·entity·Flow는 수록한다.
- 여러 진행 상태와 선택지가 연결된 상호작용도 포함한다. 추가 장면의 순서는
  실제 플레이 시간 순서가 아니며 본문에서 이 경계를 안내한다.
- 도달하지 않은 한국어 상태 9,331개는 누락된 퀘스트 본문으로 단정하지 않는다.
  귀속 불명·주변 콘텐츠·미사용 자료가 섞여 있을 수 있어 상태 목록을 보존한다.
- 한국어 본문이 없는 27개 후보 장면은 독서 장면으로 만들지 않는다. 수록 장면
  안의 한국어 미확인 참조 3개는 기록 및 자료 정보에 남긴다.

`settings/quest-supplements.json`에 DB/FlowList 해시, 퀘스트별 연결 경로, 원문 키,
raw 문자열, 한국어 redirect DB, 화자 ID, 선택지와 분기, 비귀속 상태 목록을 보존한다.
게임 DB·바이너리·개인 경로는 게시 입력에 포함하지 않는다.

## 재생성

게임별 기존 추출로 마련한 ConfigDB와 FlowLists를 입력한다. DB는 읽기 전용으로
연결하며 추출 전후 해시가 같아야 한다. 먼저 `--apply` 없이 조사할 수 있다.

```sh
python -B -X utf8 source/tools/recover_quest_sources.py \
  --configdb EXTRACTED_CONFIGDB --flowlists EXTRACTED_FLOWLISTS --apply
python -B -X utf8 source/tools/verify_quest_recovery.py --configdb EXTRACTED_CONFIGDB
```

기존 TXT의 바이트 접두부·장면 번호는 보존한다. 다시 실행하면 같은 기준선에서
추가분을 재생성하여 중복이 누적되지 않는다. 기존 설정집의 인용 해시는 기준선
바이트·인용 장면·문장의 보존을 먼저 검사한 뒤 갱신한다.

빌드·내보내기 후 `scripts/Test-PrValidationGate.ps1`로 전체 검증한다.
새 스냅샷에 본문 의미가 바뀌면 인용과 해설을 다시 검토한다.

## 검증 근거

- 한국어 redirect를 적용한 독립 DB 대조: 모든 추가 상태의 대사·선택지·중앙 문구·
  영상 자막 참조와 문자열 일치. 연결된 읽기 가능 상태의 미수록 검사 통과.
- 기존 원문 89,639개 참조 행 대조: 한국어 문장 누락 0개.
- 771개 입력·기록 파일을 동일 조건으로 재생성: 모든 바이트 해시 동일.
- 브라우저: 정확한 인용 검색 결과 2개, 검색 결과 키보드 열기, 추가 원문 구역 이동,
  대사 번호 토글, 390px 모바일 가로 넘침 없음, 버전 필터·빈 검색 복구,
  음림 임무의 중첩 화면 문구 확인.
- 전체 원문/링크/설정/게시 파일 검증은 PR의 해당 커밋 검증 기록에 연결한다.

재빌드에서 발견한 예전 맹견파 자동 페이지는 새 개별 세력 페이지로 이어지는
기존 canonical redirect 생성 경로에 포함했다. 동일 정본의 신규 탐색 항목들도
그 경로를 사용하며 예전 주소를 보존한다.
