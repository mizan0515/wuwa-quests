# 설정을 관계로 읽는 자료집

독자가 질문별 해설을 읽고, 인물·개념·근거 원문과 실제 퀘스트 대사로 이어갈 수 있게 한다. 기존 퀘스트 목록에서 설정집으로 바로 이동하는 입구를 둔다.

## 내용을 묶는 원칙

- 세계의 법칙: 주파수·잔향·울림·잔상·에코의 정의를 구분하고, 공명자의 검사 기록을 삶의 경험과 함께 읽는다.
- 도시와 문명: 금주의 방어·대피·추모, 검은 해안의 예측·선택, 리나시타의 신앙·공공 에코·생활, 라하이 로이의 구원·기술·인프라를 엮는다.
- 기록을 읽는 시선: 생태계의 관계와 조사자의 미확인 가설, 서로 다르게 말하는 원문을 구분한다.

‘원문 연결’과 ‘읽는 관점’을 문단별로 표시한다. 산화의 검사 기록과 이야기에서 서로 다르게 적힌 눈의 좌우는 나란히 읽는 비교 영역을 둔다. 어느 쪽을 정답으로 교정하지 않는다. 동일 용어·인물의 실제 대사 언급은 퀘스트 연결의 근거이며 인과관계의 확정이 아니다.

## 읽기와 탐색

기존 종이색·잉크색·금빛 테마와 Starlight 목차·검색·모바일 메뉴를 재사용한다. 해설 제목은 세리프, 본문은 16px, 근거는 작은 보조 링크로 둔다. 읽는 관점에는 배경을 주고 원문 서술 차이는 별도 비교 영역에 둔다. 주제별 카드와 인물·용어·원문 보관함은 실제 읽기 입구다.

해설 8장·인물 64묶음·개념 16개·주요 근거 50개는 정적 문서다. 상단 검색은 이 문서와 기존 퀘스트를 함께 찾는다. 전체 설정 원문 8,668개는 보관함의 종류·인물·용어·본문 검색으로 읽는다. 원자료 9,228개 ID는 동일 내용 접기 후에도 보존한다.

## 유지와 검증

빌드는 입력 파일 해시와 인용한 문자열 해시를 검사한다. 실제 클라이언트 버전은 미확인이고 기존 캐시를 다시 정리한 자료다. 개인 경로·게임 DB·키 파일은 게시하지 않는다.

정적 검사에서 단일 H1·중복 없는 이동 ID·내부 링크·인용 필드 주소·퀘스트 원본 바이트·42개 대사 언급 연결을 대조했다. Node에서 실제 보관함 코드를 실행해 본문 검색·인물 필터·중복 원자료 ID·빈 결과·실패 재시도를 확인했다. 이 검사는 브라우저 화면 검증을 대신하지 않는다. 실제 공개 화면 검증의 증거는 게시 실행 보고서에 기록한다.

관련 디자인 기준은 `UIUX-2026-10-06.md`를 적용했다. 정본 `DESIGN.md`가 없어 그 문서에 대한 준수를 주장하지 않는다.
