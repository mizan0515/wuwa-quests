# 퀘스트 문맥으로 이어 읽는 원문

퀘스트에서 같은 원자료의 다른 진행 상태를 발견하고, 자료를 옮겨도 읽던 문장과 목차로 돌아오는 흐름을 제공한다. 기존 766개 퀘스트 원문과 장면 앵커를 유지한다.

`quest-reading-context.mjs`는 현행 manifest와 dialogue-attribution의 명시적 관계만으로 독서 문맥을 만든다. 462개 퀘스트와 349개 원자료 묶음 사이의 781쌍을 SAME_SOURCE_CONTEXT로 연결한다. 이 연결은 같은 원자료의 다른 진행 상태를 함께 읽는 관계이며 임무 소유권으로 사용하지 않는다. 기존 group의 8,146개 퀘스트 장면 링크를 보존한다.

목록 밖 실제 QuestData 루트 중 한국어 문자열 표의 이름과 비시험 유형을 확인한 14개를 `quest-sources/<id>.html`에서 읽는다. 각 상태는 `state.owners['quest:<id>'].proof`가 있는 경우에만 선택하며, 다중 소유는 연결과 접힌 근거에서 함께 표시한다. 원래 현장 대화 페이지와 state/row 앵커는 유지한다. 이름 없는 233개 루트는 현행 원자료 허브와 소유 메타데이터에 남긴다. 네이티브 참조 23개 상태에는 소유자를 추가하지 않는다.

보충 퀘스트 원문은 88개 소유 상태, 503개 참조 행과 37개 분기를 담는다. 전체 임무의 수록 여부, 실행 조건, 출시 판본과 플레이 순서는 미확인이다. 기존 766개 manifest/TXT에 새 임무를 합치거나 기존 자료를 다시 귀속하지 않는다.

목록 검색은 짧은 대표 제목 외에 모든 명시적 임무 소유자의 이름과 ID를 찾는다. 두 개의 대표 제목에 가려졌던 ‘복원 배양! 적막의 절벽!’과 ‘복원 배양! 영원한 어둠의 평원!’도 같은 원자료 묶음으로 이어진다.

왼쪽 독서 문맥은 현재 글, 실제 scene/state 목차, 연결된 원문을 먼저 보여준다. 상태 목차의 이름은 원문 화자와 실제 첫 구절을 사용한다. 같은 자료에 여러 퀘스트가 연결되면 모두 표시하며 한 소유자를 자동 선택하지 않는다. 안전한 from URL로 도착한 경우에만 읽던 퀘스트·원문을 표시한다. 기본 전역 탐색과 버전 필터는 유지한다.

집중 모드는 넓은 화면에서 독자가 선택할 때만 왼쪽 메뉴를 접는다. 토글 전후의 원문 행 위치를 보존하고 같은 버튼으로 메뉴를 펼친다. 모바일 메뉴는 Starlight의 기존 메뉴·포커스 동작을 사용한다. 기존 장면·heading 앵커를 바꾸지 않으며 로컬 목차가 있는 넓은 화면에서는 오른쪽 중복 목차의 시각적 폭을 덜어낸다.

원문 연결은 기존 reading-state의 disclosure·스크롤·포커스 복귀를 재사용한다. 클릭한 링크의 원래 주소를 보관하여 from가 덧붙은 왕복 링크도 기존 포커스 대상으로 찾는다. 용어 창은 보충/현장 원문에서도 열 수 있으며 실제 state-row 위치로 복귀한다. from는 같은 사이트의 정적 HTML로 제한하고 외부·경로 탈출·잘못된 reader/state는 문맥의 소유자로 채택하지 않는다. 용어 페이지를 거칠 때도 검증된 로컬 출발 문맥 한 단계만 유지한다.

구현은 제공된 독서판의 현재 글/목차/관련 기록/명시 집중 모드 구조를 참고했다. 독서판의 게임 내용, SPA 라우터와 출시·장 순서는 가져오지 않았다. 제공 파일은 공개 생성 입력에 포함하지 않는다.

검증 명령:

```sh
node --test source/tools/quest-reading-navigation.test.mjs
python -B -X utf8 source/tools/verify_quest_reading_navigation.py --repo <owned-repo> --report <owned-report>
python -B -X utf8 source/tools/verify_quest_reading_navigation.py --repo <owned-repo> --dist <built-dist> --report <owned-rendered-report>
```

기본 stdlib 검증기는 producer를 import하지 않고 전체 모델·기존 TXT SHA·13,019개 장면 목차·14개 source reader의 본문·화자·선택지·분기·다중 소유 근거를 독립 대조한다. rendered 옵션은 766개 퀘스트와 687개 원자료 페이지의 문맥/왕복 링크 및 14개 독서 페이지 원문을 검사한다. 실제 모바일·키보드·Escape·복귀·집중 모드 검증은 생산 빌드와 실제 브라우저에서 별도로 수행한다.
