# 원문 자료집 독서 화면

명조 퀘스트 목록의 종이색·잉크색·금색 강조와 산세리프 서체를 기본으로 사용한다. 기본 탐색은 퀘스트 목록, 설정집, 지역, 인물, 세계관의 큰 설정, 자료 안내이며 페이지 종류에 따라 순서와 이름을 바꾸지 않는다. 버전과 관련 읽기는 별도 문맥 메뉴에 둔다.

지역 문서는 지역 이름, 개요, 소속·중심지·기관, 생활과 제도, 사건, 관계, 기록 비교, 원문 근거 순서로 읽는다. 금주는 방어·도시·의례·승소산의 시간, 일곱 언덕은 지형·장관부·검투사 대회·여행·사냥을 각각 실제 기록으로 설명한다. 하나의 사건을 전체 지역의 설명으로 대신하지 않는다.

세계관 입구는 소라리스, 비명, 무음구역, 에코, 소노라, 공명, 주파수, 문명을 개별 본문으로 연결한다. 사실 목록, 포함 관계, 단계, 순환, 관계 이름, 시간 변화, 관점 비교는 자료의 성격에 맞게 사용한다. 순환 표현은 깊은 바다 실험장의 기록 범위에 한정한다.

본문 위 탐색은 실제 절을 가리킨다. 관계의 양끝과 본문의 인물·장소 이름은 개별 설명 또는 원문 문서에 연결한다. 인용 링크는 고정 HTML 문서의 해당 필드 앵커로 이동한다. 원문 보관함의 자료 ID와 문단 앵커는 서로 다른 역할을 가진다.

자료집 원문, 실제 설정 해시와 인용 구절을 대조한다. 긴 원문은 보존하고 편집문에 근거를 붙인다. 원문의 주장·전승과 편집자의 해석은 주체와 표기로 구분한다. 공개 페이지와 검색 입력에는 내부 작업 문서를 포함하지 않는다.

320px 화면의 본문 폭, 모바일 관계 배치, 키보드 포커스, 빈 검색, 개별 문서 이동과 브라우저 복귀를 확인한다. 공통 스타일은 reading-system.css, 공통 탐색은 Sidebar.astro, 본문 구조는 reading-sections.mjs에서 관리한다.
