# 세력·위협을 읽는 연결

잔성회: 스카의 생태, 플로로의 소개·회장 발언, 사이보그의 생태, 루크·린네의 발언, 추방자의 통신과 「첫 마주치는 잔성」 장면 7을 대조한다. 소속은 분기 관계로, 인간·잔상·기계 부품의 결합은 확인된 변형 과정으로 표현한다. 플로로와 회장의 상호 이용 관계는 플로로의 발언으로 표시한다. 파괴·힘 추구·회장의 정체를 조직 전체의 단일 목적이나 확정된 동일성으로 확대하지 않는다.

스카: 인간·특수 형태의 생태와 양양의 소개, 방랑자를 친구로 부르며 선택을 기대하는 발언을 함께 읽는다. 생태 기록과 각 인물의 평가를 분리한다. 퀘스트 장면 링크는 대사를 읽는 자리로 이동한다.

명식: 도움말의 정의에서 레비아탄의 개체 기록과 알레프-원의 창조물 기록으로 분기한다. 허무의 신과 알레프-원을 동일한 개체로 합치지 않는다. 엑소스트라이더가 재난을 봉인했다는 기록과 보이드웜의 생태는 라하이 로이의 지역 사례다.

흑조: 현상의 정의, 수도회가 전한 역사, 순례의 땅의 실험, 레비아탄의 육체 기록을 대조한다. 성녀의 희생에 관한 수도회 기록과 명식 생태의 서술 주체를 표시한다. 리나시타와 금주에서 관련 세력 본문으로 이동하는 경로를 둔다.

새 본문 4개와 GNB의 세력과 위협을 추가한다. 기존 reading-kit의 관계·순환·과정·비교·출처 템플릿을 사용한다. 설정집에서 인용한 퀘스트는 장면별 원문 블록과 전체 파일 SHA-256을 공통 데이터에 연결한다. 원문 전체를 유지하고 해설·관계만 별도로 편집한다.

검증은 전체 설정 근거·퀘스트 원문 해시·사이트 링크 검사와 공통 QA를 사용한다. 실제 브라우저에서는 관계명→근거→원문→복귀, 인물 본문과 세력 본문의 연결, 좁은 화면의 세로 배치를 확인한다. 수동 편집 묶음은 21개이며 전체 원문의 수동 편집 완료와 구분한다.
