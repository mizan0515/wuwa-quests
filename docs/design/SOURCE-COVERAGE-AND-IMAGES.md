# 지역·세력 원문과 게임 이미지 확장

## 질문과 읽기 구조

황룡은 수도·6개 주·금주의 변방 방어와 몽주의 인물을 함께 읽는다. 신 연방은 인물 소개의 출신과 실제 소속, 학술강연과 교류를 구분한다. 로야 빙원은 비명 이후 자극 변화·한랭화·지하 이주·수송 과정의 기록을 잇는다. 아시노하라는 무녀·방어·종·도시와 인물의 기억·교역을 대조한다. 유령사냥단은 카카루의 과거·맹견파 병합·용병 계약과 인물의 관계를 연결한다.

새 묶음은 원문 인용과 SHA-256을 각 서술·관계·사건에 연결한다. 포함 관계, 관계도, 사건 흐름과 과정은 공통 reading-kit으로 표시한다. 관련 설정과 인물 이름은 개별 본문으로 이동한다. 기존 클러스터와 원자료 records는 보존한다.

관계 검토에서 야귀군→금주 방어의 방향, 비명→로야 빙원의 극점 변화라는 문장, 맹견파의 ‘병합된 조직’ 분류를 실제 구절에 맞췄다. 출신과 소속의 원문 필드를 개별 앵커로 공개하여 인물 국가·활동 조직의 혼동을 줄였다.

## 게임 이미지와 인물 본문

실제 RoleInfo의 인물 ID·이름·이미지 경로를 대조하여 64명의 아이콘과 초상화 128개를 연결했다. 원본 텍스처는 설치본 밖에서 추출·검증하고 무손실 WebP로 변환했다. 이미지 provenance에는 상대 자산 경로, 원자료 해시, RoleInfo 필드, 크기와 파일 해시를 기록한다. 인물 목록의 이미지 링크는 기존 인물 본문을 가리킨다.

인물 본문은 원문 소개와 초상화를 먼저 보여주고, 관계도는 전체 독서 영역 너비로 배치한다. 모바일에서는 초상화·소개·관계를 순서대로 읽는다. 972px·320px에서 이미지 로딩과 가로 넘침을 확인했다. 초상화가 관계도를 좁히던 초기 배치는 수정했다.

## 공통 화면과 검증

양쪽 사이트의 reading-kit 1.3.0은 같은 파일과 해시를 가진다. 목록의 분류 제목을 항목 위에 배치하고 실제 독서 영역 너비에 맞춰 열 수를 조절한다. 테마 선택의 아이콘·문구·화살표 여백을 통일했다.

1,048개 HTML의 내부 링크·앵커 91,489개, 원문 보관함 경로 1,099개, 설정 근거 113개와 기존 퀘스트 766개를 확인했다. 128개 이미지의 인물 ID·이름·RoleInfo 경로·파일 및 자산 해시·무손실 WebP 헤더와 크기 검사가 통과했다. HTML 행 끝의 원문 공백은 숫자 문자 참조로 출력하여 읽기 텍스트를 보존한다.

전체 게임 설정을 모두 해설한 범위로 표현하지 않는다. 이번 검증은 추가된 지역·세력 묶음, 공통 화면과 인물 이미지에 해당한다. 내부 기록과 개발 규칙은 독자용 생성 입력에 포함되지 않는다.
## 원문 HTML 보존

중첩 HTML의 원문에 빈 줄이 있으면 Markdown HTML 블록이 끊겨 문단 태그와 스마트 문장부호가 원문에 들어갔다. HTML에 삽입하는 CR/LF는 문자 참조로 직렬화하고 Sätteri의 smartPunctuation을 껐다. 브라우저 textContent와 원자료를 직접 대조한다. 신규 QA는 64명 프로필·이야기·소장품과 선별 원문 129개, 퀘스트 766개/9331장면/97860표시 행 및 선택·분기를 검증한다. 구형 export에서 182개 차이가 검출됐고 수정 빌드는 모두 통과했다.


## 인물 분류와 2장 주요 인물

기존 인물 목록의 입력은 프로필을 가진 64명이다. 대사 중심 인물은 별도 `npc-people.json`에 같은 인물 종류로 수록하고, 목록은 두 입력을 합쳐 74개 본문으로 연결한다. 스카는 인물로 이동했으며 기존 세력 주소는 검색 조건과 앵커를 보존하여 인물 본문으로 연결한다. 조직의 소속과 개인의 행적은 관계 이름으로 구분한다.

크리스토포로, 아비디우스, 펜리코, 네스토르, 발렌티나, 알렉시스 사제, 엔젤, 안토니오, 잔성회 회장을 추가했다. 인물의 지역 활동, 자기소개, 소속에 대한 다른 인물의 발언, 지시와 협력 관계를 장면 문맥으로 대조했다. 스카의 방랑자 영입과 거절 선택지의 위협, 금희의 체포, 크리스토포로의 주파수 이동 설명, 플로로와의 동행을 보완했다. 플로로가 피날레 완성을 도운 상대는 크리스토포로로 명시한다.

펜리코는 수좌 본인의 설명과 그 모습으로 변신한 흑조의 창조물을 별도 관점에 배치한다. 카론(슈바르츠로흐)과 이후 회장의 동일 신원은 추가 확인 범위다. 관계의 근거는 인물의 발언과 원문에 근거한 요약, 편집 관계 표현으로 표시한다. 인물 목록의 검색·복수 활동 지역 필터를 유지하며 지역에서 관련 인물 본문으로 연결한다.

역할과 등장 지역을 관계도 앞에 두고, 주제별 설명에 이미 연결된 인용의 독립 본문 반복을 줄였다. 원문은 설명의 근거 펼침 및 전체 장면 링크, 하단 자료 목록에서 유지한다. 10명 인물 자료의 66개 고유 근거는 원문 해시·장면·화자·인용 문자열과 실제 HTML·앵커를 검증한다. 기존 64명 프로필과 766개 퀘스트도 전문 대조한다.

파생 `curated-sources.json`은 생성 중 확장한 129개 개별 원문 경로를 기록한다. 보존된 원본 `index.json` SHA와 canonical record, 해시 slug, 기존 mapping의 일치 여부를 QA한다. 원본 index와 전체 records는 보존한다. 내부 개발 문서는 생성 입력과 검색 색인에서 분리한다.
