# 미귀속 대화 상태 전수 조사 (2026-10-12)

사용자가 지정한 기존 미귀속 목록 9,331개를 고정 코호트로 삼았다. 대화 상태는 대사 한 줄과 다르다. 한 상태에 여러 발화·선택지·화면 문구·영상 자막이 들어갈 수 있다.

임무 → 탐색 → 개체 → 공용 설정 순으로 대표 분류를 정했다. 복수 소유 참조는 모두 보존한다. `quest-supplements.json`의 기존 목록과 기존 766개 퀘스트 본문은 변경하지 않는다. `dialogue-attribution.json`에 모든 후보와 문자열 키, 원문, 화자, 선택지, 분기, 호출 경로를 보존한다.

한국어를 확인한 8,740개 상태의 40,197개 발화·선택지·문구·자막 행을 687개 원자료 묶음으로 읽을 수 있게 수록했다. 문자열 키는 39,231개다. 호출 대상을 확인하지 못한 자료도 원문 목록의 별도 필터에서 읽을 수 있다. 원자료의 시험 표기를 포함하는 11개 묶음은 기본 목록에서 숨기며, 필터로 표시할 수 있다. 확인된 호출은 실행 가능성, 출시 시점, 플레이 순서를 증명하지 않는다.

## 입력과 귀속 근거

2026-10-08 추출 스냅샷의 SQLite/FlatBuffers와 FlowLists를 읽기 전용으로 사용했다. 현재 설치본과의 일치는 미확인이다. 이전 조사에서 사용한 13개 DB와 FlowLists 해시를 먼저 대조했다. 상태의 `FlowListName + FlowId + StateId`, 정확한 참조 토큰, 상대 상태 전환, 전용 던전 지도와 탐색 콘텐츠 연결을 역추적했다. 다른 임무의 선행 조건인 `q_` 참조, 파일명 유사성, 화자 이름만으로는 임무에 귀속시키지 않는다. 지도 개체는 SQL MapId/EntityId와 FlatBuffers 필드 1/2를 대조했다.

추가로 494개 DB의 2,076개 BinData 테이블, 910,034개 행, 126,513개 유효 UTF-8 JSON 필드를 조사했다. 공용 설정의 79개는 templateconfig/FB3 48개, plotreference/FB1 22개, giantresponse/FB3 8개, loopteleportvolumefunction/FB4 1개다. 각 SQL Id와 FlatBuffers 필드 0을 대조하고 정확한 JSON 호출 또는 직렬화된 대화 삼중항을 확인했다. 템플릿의 이름은 명시 TidName으로 표시하지만 실제 배치·지역·퀘스트는 추정하지 않는다.

미확인 1,877개는 위 읽을 수 있는 설정 범위에서 사용 참조를 확인하지 못했다는 의미다. 전체 바이너리와 실행 코드에 참조가 없다는 결론은 아니다. 지원하지 않는 루트·중첩 테이블 형식 8,572개 행과 런타임 사용 조건은 미확인으로 남긴다.

## 검증과 재생성

`source/tools/attribute_dialogues.py --configdb <ConfigDB> --flowlists <FlowLists>`가 고정 목록을 조사한다. `source/tools/verify_dialogue_attribution.py`는 전체 후보·원문·분류·수록 범위를 검사한다. 같은 스냅샷을 지정하면 원문 문자열·화자와 10,984개 고유 호출 경로를 별도 JSON 위치 해석으로 재검증한다. `--dist source/dist`는 687개 독서 페이지에서 모든 원문 행의 순서·본문·화자와 기존 장면 링크를 비교한다.

빌드는 독서 페이지와 목록을 생성하고 전체 본문 검색 색인에 연결한다. 목록 검색·분류·시험 표기·더 보기·초기화는 브라우저에서 확인한다. 기존 퀘스트 원문·설정 설명·인용은 전체 회귀 검증과 현재 Git diff로 보존을 확인한다.
